# Chapter 2: IDE superpowers

CTRL+Spacebar: manual autocomplete
Introspection: hover on variables and declarations

#### JSDoc comments:

JSDoc comments will display on introspection.

```
/** Description
/* @param - Describe parameter
/* @example - Describe example in markdown
/* @returns - Describe what is returned
```

Go to definition/references: click/select variable and hit F12
Rename symbol: click/select symbol and use F2 to rename
Quick fixes: select code and use CTRL-. for quick fixes
Restart language server: CTRL-SHIFT-P -> search Restart TS server
